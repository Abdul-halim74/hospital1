# Nirmol Health Trust — hospital website demo (HTML, CSS, JavaScript, jQuery)

Open `index.html` in a browser. All images are local SVG files; internet is only
needed for jQuery (code.jquery.com), Google Fonts and the Google Map on the contact page.
All names, phone numbers and addresses are fictional.

Pages: index, about, find-doctor (department / branch / name wise), services, units,
patient-care, contact.

Files
- css/style.css            — all styles (light + dark mode)
- js/data.js               — units, doctors, services, slider text, gallery
- js/main.js               — jQuery: menus, slider, notice modal, doctor carousel,
                             gallery lightbox, filters, Ctrl+K site search
- images/logo.svg          — demo logo
- images/slider/*.svg      — 5 slider banners (text is HTML, set in js/data.js → SLIDES)
- images/gallery/*.svg     — 7 illustrated scenes (gallery + section images)
- images/icons/*.svg       — 11 service / quick-link icons
- images/avatars/*.svg     — 8 doctor avatars (4 male, 4 female)

To use real photos later, put JPG/PNG files in images/ and change the paths in js/data.js.
